# 古船模型索具齐套核对台

按船型与桅杆数量维护标准索位（名称 + 应有数量）；模型建档带出对应标准，
登记实际安装的索位后自动列出**缺装**与**重样**：

- 缺装/重样没补齐，模型停在「待检查」，进不了「校准中」（状态变更由服务端闸门拦截）。
- 标准修订后版本号 +1，已有模型结论自动重算，原先通过的结论作废，退回「待检查」。
- 标准之外登记的索位同样计为重样。

业务代码分为三份：

| 文件 | 职责 |
| --- | --- |
| `standards.js` | 标准资料：按船型 + 桅杆数维护索位名称与应有数量，版本管理 |
| `completeness.js` | 齐套判定：缺装/重样比对、进入校准的闸门、改版重算 |
| `page.js` | 页面：标准维护页签 + 齐套核对台（建档、登记/撤装、状态锁定） |

`server.js` 只做 HTTP 装配与数据存取，数据保存在 `data/model-rigging-calibration.json`。

运行：

```bash
npm start
```

访问 `http://localhost:3038`：

- **齐套核对**页：建档（选择标准自动带出船型与桅杆数）、逐条登记实际索位，
  卡片显示应有/已装对照表、缺装与重样数量；未齐套时状态下拉锁定在「待检查」。
- **标准资料**页：录入或修订标准（船型 + 桅杆数 + 索位清单），保存即触发在档模型重算。
